# CineForge Agent 中文界面默认方案

## 目标

让 CineForge Agent 的用户界面默认以中文展示，保留产品名称和可选语言切换能力。

## 设计

- 在 i18n 初始化时明确使用 `zh` 作为启动语言，避免浏览器语言或历史本地存储的英文偏好覆盖中文默认值。
- 保留语言切换入口，用户仍可在设置中临时切换到其他语言；页面刷新后回到中文。
- 将少量不经过 i18n 的可见英文设计标签替换为中文。
- `CineForge Agent` 作为品牌常量与页面标题的一部分保持不变。

## 验证

1. i18n 初始化结果为 `zh`，即使浏览器探测结果为 `en`。
2. 前端测试与生产构建通过。
3. 本地 Docker 容器重建后状态为 healthy，首页可访问。
